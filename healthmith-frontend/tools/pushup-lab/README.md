# 정면 푸시업 비교 도구

제품 주소가 아닌 개발 전용 실행 도구다. 입력 영상은 로컬 브라우저 파일로 열고, 서버에 업로드하지 않는다. 기존 픽셀 판정기와 어깨 이동/어깨 너비를 이용한 후보 판정기에 같은 프레임을 넣는다. 두 결과를 합산하지 않는다.

```sh
pnpm prepare:pose
node tools/pushup-lab/run.mjs '/영상/정면.mp4' 5 standard ./test-results/frontal-01.json
```

두 번째 인자는 **사람이 직접 센 정답**이다. 무릎 푸시업은 `knee`, 빈 화면·팔 흔들기·준비 자세 이동·카메라 흔들림은 `negative`와 정답 0을 넣는다. 필요한 영상 권한과 정답을 확인한 뒤 실행한다. 개인 영상은 커밋하지 않는다.

현재 판정기 ID는 `frontal-shoulder-1-candidate`다. 어깨·손·골반의 가시성, 정면 배치, 손 위치 변동을 확인한다. 어깨 이동을 어깨 너비로 나눠 거리 영향을 줄인다. 추적 누락/휴식 때 미완성 왕복은 폐기한다. 이 조건만으로 실제 인식 정확도가 검증된 것은 아니다.

현재 저장소 푸시업 관절 데이터는 측면/사선이며 정면 정답 영상이 없다. 정자세 3개, 무릎 3개, 음성 사례 4개 이상을 사람이 라벨링한 뒤 비교 결과를 남겨야 한다. 사람·조명·속도가 겹치지 않는 검증 영상을 따로 유지한다. 승인 전까지 카메라 정확도나 무릎 푸시업 인식 완료를 주장하지 않는다.
